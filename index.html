Rasterix

How does a triangle become a pixel?

Java

  1. x′ = (f/a)·x / w   y′ = f·y / w

    Divide by depth: far points move toward the centre. That is perspective.

    f = 1 / tan(fov/2)  ·  w = −zcam

  2. Eab(p) = (p − a) × (b − a)

    A pixel is inside when it sits on the same side of all three edges. The same three numbers become its weights.

    wᵢ = E / area  ·  inside when all wᵢ ≥ 0

  3. z = w0za + w1zb + w2zc

    Blend the corner depths with those weights, and draw only if nothing nearer is already there.

    kept only if nearer than the z-buffer

  4. k = 0.16 + 0.84·max(0, n̂·l̂)

    A face turned toward the light is brighter. The dot product measures how directly it faces it.

    n̂ from the cross product of two edges

Experiment 01 / Dynamical systems

A little chaos

Lorenz attractor

How can a simple system become unpredictable?

Three coupled equations with σ = 10, ρ = 28 and β = 8/3, stepped with forward Euler at dt = 0.01. The notebook also covers phase space and the Van der Pol oscillator.

ẋ = σ(y − x) ẏ = x(ρ − z) − y ż = xy − βz

Python / Matplotlib

Archived Open the project

01 / 05

chaotic is not the same as random

The trajectory never repeats and never settles, yet it stays on the same two-lobed shape. Bounded but unpredictable was the idea I wanted to see.

Experiment 02 / Numerical integration

Everything pulls on everything

Particle simulation

What happens when particles only feel gravity and each other?

Particles fall toward a point with an inverse-square pull (softened below a distance of 5 so nothing divides by zero), bounce off each other with elastic collisions, and stay inside a sphere. Rendered with OpenGL; released for macOS, Linux and Windows.

C++ / OpenGL / GLM / CMake

Working prototype Open the project

02 / 05

compare with the fluid sim's integrator

Velocity Verlet averages the old and new accelerations, so it needs the force evaluated twice per step. That ordering is the whole difference from the semi-implicit Euler loop in the fluid simulation.

Experiment 03 / Computational biology · hackathon

Reading the quiet genome

Myelovar

Which non-coding variants could plausibly matter in multiple myeloma, and why?

Seven stages, s0 to s6. Load the variants, drop common ones, keep those inside 18 ENCODE regulatory tracks from MM.1S myeloma cells, score transcription-factor motif disruption in a ±30 bp window, link each element to a target gene, weigh myeloma relevance with DepMap CRISPR data, then rank.

Python / FastAPI / React / 33 tests

Working prototype Open the project

03 / 05

research use only, not a diagnostic

Most of the work was making each filter explainable. Every surviving variant carries a plain-English evidence chain, so a reader can see which stage kept it and why.

Experiment 04 / Software · desktop assistant

An assistant I can read

Buffy

What would a personal assistant look like if I could read every line of it?

An Electron and TypeScript assistant that can run a local model through Ollama or Claude through the API. Every tool is tagged with a scope; reads run freely, while file deletions, shell commands and anything external wait for a click. A pause switch denies every call until it is turned off.

TypeScript / Electron / Vitest
